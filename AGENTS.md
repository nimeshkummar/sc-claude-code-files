# Project Agent Instructions

## Public repository boundary

This repository is public. Never commit personally identifying, confidential, or account-specific information. Generalize personal context in transcripts into reusable technical or educational framing.

Before committing, remove or generalize:

- real names, usernames, email addresses, and account identifiers;
- assessment scores, diagnoses, health information, or other sensitive traits;
- private principles, value systems, or personal shorthand;
- employer, career, role, customer, or family details;
- locations and access/topology information; and
- absolute paths containing usernames—use `~/` or repository-relative paths.

Review staged content for these categories before every commit.
